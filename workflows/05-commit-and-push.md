# Commit and Push

Part of the [revision workflow](../WORKFLOW.md).

### Step 8 — Commit

Use focused commits.

Commit messages should clearly describe the change. Prefer `feat(orders): add order creation tests` over `stuff` or `changes`. When useful, use the revision number: `feat(rev-003): add order tests`.

Do not include unrelated changes in the commit.

### Step 9 — Push the branch

Push the revision branch to GitHub.

Verify that:

- The correct remote is configured.
- The correct branch was pushed.
- The branch contains only the intended revision.
